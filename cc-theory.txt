1. Explain the different Data Privacy Attacks or Data Breaches
Answer: Data privacy attacks and breaches refer to unauthorized access, disclosure, or
misuse of personal or sensitive information. Common types include:
• Phishing Attacks: Fraudulent attempts to obtain sensitive data by impersonating
legitimate entities.
• Malware: Software designed to infiltrate and gather data from systems.
• Man-in-the-Middle (MitM) Attacks: Interception of communication between two
parties to eavesdrop or modify data.
• SQL Injection: Inserting malicious queries into input fields to access or alter
database information.
• Insider Threats: Employees or trusted individuals misusing their access to data.
• Credential Stuffing: Using leaked credentials from one breach to access other
accounts.

4. Explain the different aspects of DFIR Framework
Answer: DFIR stands for Digital Forensics and Incident Response. Its framework
includes:
• Identification: Detecting and acknowledging a potential incident.
• Preservation: Safeguarding and documenting evidence.
• Collection: Gathering data from systems, networks, and logs.
• Examination: In-depth analysis to uncover patterns and indicators.
• Analysis: Drawing conclusions about how, when, and why the breach occurred.
• Containment: Isolating affected systems to prevent further damage.
• Eradication: Removing malicious elements.
• Recovery: Restoring systems to normal operation.
• Reporting: Documenting findings for legal, compliance, or internal review.

data.

8. Analyse the Buffer Overflow Attack and Outline the Countermeasures
Answer: Buffer Overflow Attack occurs when data exceeds the buffer’s storage capacity
and overwrites adjacent memory.
• Impact: It can cause crashes, arbitrary code execution, and privilege escalation.
Countermeasures:
• Bounds Checking: Validate data length before storage.
• Canaries/Stack Guards: Use markers to detect overwritten buffers.
• ASLR (Address Space Layout Randomization): Makes memory layout
unpredictable.
• DEP (Data Execution Prevention): Prevents execution of code in data regions.
• Use Safe Libraries: Prefer functions like strncpy() over strcpy().
9. Classify and explain different types of IDS
Answer: IDS = Intrusion Detection System. Types include:
• Network-based IDS (NIDS): Monitors network traffic for suspicious activity.
• Host-based IDS (HIDS): Monitors a single host for changes in files, logs, or system
calls.
• Signature-based IDS: Detects known attack patterns (like antivirus).
• Anomaly-based IDS: Uses behavioral baselines to detect unusual activity.

11. Model the RSA algorithm with all the steps involved with an example
Answer: Steps:
1. 2. 3. 4. 5. 6. 7. 8. Choose two primes: p = 3, q = 11
Compute n = p × q = 33
Compute φ(n) = (p−1)(q−1) = 2×10 = 20
Choose e such that 1 < e < φ(n) and gcd(e, φ(n)) = 1; e = 7
Compute d such that (d × e) mod φ(n) = 1; d = 3
Public Key = (e, n) = (7, 33), Private Key = (d, n) = (3, 33)

Decryption: Message = (Cipher^d) mod n = (29^3) mod 33 = 24389 mod 33 = 2

41. Model Diffie-Hellman key exchange protocol.
Answer:
Steps:
1. Both parties agree on a prime number p and base g (public).
2. Alice selects a secret number a, computes A = g^a mod p and sends to Bob.
3. Bob selects a secret number b, computes B = g^b mod p and sends to Alice.
4. Alice computes shared secret S = B^a mod p.
5. Bob computes shared secret S = A^b mod p.
Result: Both derive the same shared key S without transmitting it directly.
42. Identify the effect of a single-bit error in the ciphertext when using the CBC, ECB
modes of operation?
Answer:
• ECB (Electronic Codebook):
o Single-bit error affects only the corresponding block.
o No error propagation.
• CBC (Cipher Block Chaining):
o Single-bit error affects the current and next block.
o Due to chaining, error propagates partially.
Conclusion: CBC offers better security but is more sensitive to errors.

46. Identify the various steps that take place in AES key scheduling with proper steps.
Answer:
AES key scheduling generates round keys from the original cipher key.
Steps:
1. Initial Key Copy: Original key copied as the first part of expanded key.
2. Key Expansion Loop:
o Use previous 4-byte word to calculate next one.
o Apply RotWord: Circular left shift of last word.
o Apply SubWord: Substitute bytes using AES S-box.
o XOR with round constant (Rcon).
o XOR with word from 4 positions before.
3. Repeat until full round keys are generated.
Number of Rounds:
• AES-128: 10 rounds (11 keys)
• AES-192: 12 rounds (13 keys)
• AES-256: 14 rounds (15 keys)

o Attacker can encrypt arbitrary plaintexts.
o Observes ciphertexts to find patterns or keys.
o Example: RSA vulnerabilities when low exponent is used.
